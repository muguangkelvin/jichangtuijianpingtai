# 评测方法与数据核验标准

为了保证机场推荐平台所有测评结果的**客观、公正、可核验**，编辑部在测试与评估各网络代理服务商时遵守以下统一的技术标准：

## 1. 节点连通率与延迟测试 (Ping & Handshake)
- 使用专业网络测试工具在不同时段（早晨、下午、晚高峰 20:00-23:00）对节点的 ICMP 延迟与 TCP 握手时间进行 100 次连续测试。
- 计算平均延迟与丢包率，剔除偶发抖动。

## 2. 晚高峰带宽与吞吐量实测 (Bandwidth & Speedtest)
- 采用千兆家用宽带（电信、联通、移动多线）环境，在 21:00 晚高峰进行 Speedtest 跑分与 4K/8K YouTube 视频播放码率记录。

## 3. IP 纯净度与流媒体/AI 解锁能力
- 验证节点 IP 是否为原生 IP (Native IP)。
- 跑分检测 Netflix、Disney+、HBO Max、ChatGPT (OpenAI 1020 风控) 及 Claude 解锁状态。

## 4. 价格、套餐与优惠码周期核验
- 每周定期人工对服务商官网结算页的价格、流量重置规则及优惠码有效性进行复核。
