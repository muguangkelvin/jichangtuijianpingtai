节点超时与订阅无法更新？魔法机场新手常见 5 大故障排查

在日常使用网络代理工具的过程中，不少新手朋友经常会碰到“昨日还能正常使用，今天节点全部显示 Timeout 红色报错”或者“订阅更新提示 504 网关超时”等突发故障。遇到这些情况先不要慌张，绝大多数故障都是由配置冲突或本地网络环境变化引起的。

机场推荐平台总结了新手最常遇到的 5 大常见故障及对应的快速解决方法。

故障一：节点列表全部显示 Timeout 红色超时

现象描述：点击延迟测试后，所有节点都显示红色 999ms 或 Timeout。

排查步骤：

1. 检查本地网络：确认在关闭代理客户端时，电脑能否正常打开国内百度、新浪等网站。

2. 检查系统时间：Windows/Mac 系统时间如果偏差超过 1 分钟，会导致 TLS 握手失败。请在系统设置中开启“自动同步时间”。

3. 更换连接节点：个别入口服务器维护可能导致部分节点超时，尝试切换到其他地区的备用节点。

故障二：订阅链接更新失败（提示 504 / 404 / Invalid Config）

现象描述：在 Clash 或 Shadowrocket 中更新订阅时提示链接超时或解析错误。

排查步骤：

1. 官网防失联检查：登录机场官网，查看节点域名是否被污染并更换了新订阅链接。

2. 开启代理更新：先连接一个尚可使用的节点，再尝试点击“更新订阅”。

3. 检查套餐过期状态：登录后台确认您的流量是否已经耗尽或套餐已到期。

故障三：网页无法打开但 Telegram / 游戏正常

现象描述：社交软件能连上，但 Chrome 浏览器打开网站提示 ERR_CONNECTION_RESET。

排查方案：这往往是由于本地 DNS 污染引起的。在客户端设置中将远程 DNS 强制修改为 1.1.1.1 或 8.8.8.8，或开启 TUN 模式重新接管网卡。
